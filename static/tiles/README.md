# Kokshetau offline basemap

These 1,253 raster XYZ tiles cover 53.19–53.36 N, 69.28–69.57 E at zoom levels 11–15, plus a one-tile viewport buffer that prevents edge requests from returning 404 errors.
They were rendered locally on 2026-08-26 from a single bounded OpenStreetMap data extract obtained through the Overpass API. No public raster tile service was scraped or cached.
